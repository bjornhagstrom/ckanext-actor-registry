# Code of conduct

We want participation in this project to be safe, respectful and constructive.

Be considerate, assume good intent, welcome questions and critique ideas rather
than people. Harassment, discriminatory language, threats, deliberate
disruption and publication of another person's private information are not
acceptable.

Project maintainers may edit or remove contributions and restrict participation
when this code of conduct is violated. Reports should be made privately to a
maintainer through the repository's available private contact channel. Reports
will be handled as confidentially as practical.

This code applies in the repository and in public spaces where someone is
representing the project.
