# Security policy

## Supported versions

Until a later release is available, security fixes are made only on the latest
0.2.x release. Version 0.2 is alpha software and has not received a formal
security audit.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's
**Report a vulnerability** function in the repository's Security tab. The
maintainer will acknowledge the report, assess impact and coordinate a fix and
disclosure. If private vulnerability reporting is temporarily unavailable,
open a public issue containing no sensitive detail and ask the maintainer for a
private contact channel.

Do not include live credentials, personal data or data copied from a production
CKAN installation in a report.
